# Aevum Client

基于 [Frog](https://github.com/awds14592478/FrogClient) 魔改的 Minecraft 1.21.1 Fabric 客户端，针对 2b2t.xin。

## 安装

1. 下载 `aevum-client-1.0.0.jar`
2. 放进 `.minecraft/mods/`
3. 启动游戏

需要 Fabric Loader >= 0.15.0、Java 21、Fabric API。

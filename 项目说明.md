# RotationManager 源码

Minecraft 1.21.1 服务端静默旋转管理器，带 GCD 量化。

## 目录结构

```
rotation-manager/
├── README.md
├── LICENSE
├── .gitignore
└── src/
    └── main/
        └── java/
            └── gg/
                └── alter/
                    └── rotation/
                        └── RotationManager.java
```

## 快速开始

```bash
git init
git add .
git commit -m "Initial commit: RotationManager with GCD quantization"
git branch -M main
git remote add origin https://github.com/<你的用户名>/rotation-manager.git
git push -u origin main
```
